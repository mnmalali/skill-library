# Contributing

Contributions should preserve the Markdown-first design: the shared collection is a folder of skill bundles, indexes, and a catalog; management is described by the two `SKILL.md` files. Open a focused pull request that explains the user workflow it improves. Validate frontmatter against the [Agent Skills specification](https://agentskills.io/specification), check relative links, and try the affected management skill in a disposable library before proposing a change.

Do not add third-party skill bundles without their provenance and redistribution rights. Use the private reporting channel in [SECURITY.md](SECURITY.md) for vulnerabilities.
