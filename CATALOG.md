# Skill catalog

This catalog records provenance and review status for collected skills. The library starts empty.

| ID | Skill | Library path | Source and revision | License | Review status |
| --- | --- | --- | --- | --- | --- |

Assign each new skill a stable, unique ID such as `accessibility-audit-1`. Keep its ID when moving categories. Use `Unreviewed` until a person has inspected the skill and approved it for project installation. An unknown license is recorded as `Unknown`, not assumed to be redistributable.
