# Setup Skill Library

Use the `skill-library` CLI. Default to the canonical `~/Skill-Library` directory, shared by all agents. For initialization, run `skill-library init`. For imports, inspect without execution, check duplicates and collisions, then run `skill-library add`. Review imported content before marking it trusted. For reorganization, dry-run first, preserve distinct bundles, and update hierarchical `INDEX.md` files. Read `references/WORKFLOW.md` for command examples.
