# Security policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature on this repository. Do not open a public issue containing exploit details or secrets. Maintainers will acknowledge reports and coordinate disclosure.

Imported skills are untrusted data. Importing, searching, and indexing do not execute scripts. Review every skill before `trust` or project installation. The CLI checks paths, file types, sizes, hashes, and collisions, but cannot prove instruction safety. Do not publish third-party skills unless their licenses permit redistribution.
